## Findings

1. **gap (L3)** — flake reproduced 3× in ~13 fresh runs (≈23%, at/above
   the ~20% lore): the determinism clause fails on a provider-only tie —
   two catalog models with equal `ref`/`keyless`/`context_length` and
   `provider: Some(..)` vs `None`; provider is not part of the sort key,
   so reversing the input reverses the tie. Minimal counterexamples
   observed: `ref "5"` (keyless true) and `ref "r"` (keyless false).
   Pre-existing on `main`, untouched by T15 (the L3 generator and sort
   key are unchanged by the tri-state). Aggravator: after each red,
   proptest auto-persists the case to
   `tests/laws.proptest-regressions`, pinning every later run red until
   the untracked file is deleted — a CI red will stay red forever (same
   trap T12 documented). Owner decision pending since T02/T08/T10/T12:
   scope the determinism clause or tie-break the sort.
2. **note (spec)** — the spec's mandated doc clause "the loop treats
   `-` as `1`" is not true of the unchanged loop read mechanically:
   `[ "-" != "1" ]` is true, so the loop sends `-` **into** the
   credential gate (same as `0`) — which is exactly the spec's own
   oracle ("still passes `-` through the gate", verified above). The
   clause was written verbatim as specified, and the same step now also
   records the failsafe fact, so the doc cannot be read as "the third
   value unlocks a leg". Owner may want to reword the clause to
   "treats `-` as gated" once read in context.
3. **note (D2 coverage)** — per spec ("keep `1|0` for tier routes"),
   T15 implements D2's tri-state for direct ids only. T09's D2 wording
   also covers the non-cheap `tier:*` routes, whose stamped-default
   `keyless: true` (e.g. vector `expensive_outside_catalog_typed_unknown_provider`)
   still renders `1`. Left as is — spec scope. Union note: `p1-T09`
   carries its own P1.md `## Decisions` D2 row (proposing the tri-state);
   this branch carries a T15-updated D2 row (implemented) and created the
   `## Decisions` heading, absent on `main` — one-row reconcile needed at
   union time.
