# Laws — P1 dispatch policy

A law is: **id · statement · incident it closes · mechanism that checks it**.
A law without a mechanism does not belong here (see `kernel/laws/README`
rule below). The Bend lab mirrors this file as `LAWS.bend`.

| Law | Statement (∀ inputs) | Incident | Mechanism |
|---|---|---|---|
| L1 | Chain fields are typed; the wire format `render_us`/`parse_us` round-trips exactly and a field containing a delimiter cannot become a chain | `e82f008` (TSV read keyless flag as provider "1") | type `ChainEntry { provider: Option<String>, keyless: bool }`; `tests/laws.rs::l1_us_wire_roundtrip`, `l1b_delimiters_are_rejected` |
| L2 | No entry whose registry `id_status` contains FANTASMA / NAO-ENCONTRADO / NAO-VERIFICADO ever appears in a cheap chain | E5-M2 | `l2_l4_l5_l6_cheap_gates`; vector `cheap_with_openrouter_credential` |
| L3 | Cheap order is keyless → context desc → ref asc, and is a pure function of catalog content | E5-M4 / R1 | `l3_cheap_order`; differential check vs `lib-oracfit-mode-loader.py resolve-tier` (identical on 2026-09-19 data, 11 refs) |
| L4 | A non-keyless entry appears only if its provider has a **file** credential; the environment is never an input | E5-M5 | `Inputs.credentials: &BTreeSet<String>` is the only credential input; `l2_l4_l5_l6_cheap_gates`; vector `cheap_zero_key_only` |
| L5 | The free route never yields a provider outside the owner allowlist; a catalog citing one is a violation, not a skip | E5-M6 / R4 | `l5_outside_allowlist_is_a_violation`; vector `cheap_provider_outside_allowlist_is_loud` |
| L6 | A chain is never empty; every failure is a typed `PolicyError`; no catalog ⇒ `CatalogMissing`, never a hardcoded default | E5 (dead default served as first option) | `Chain::new` rejects empty; `l6_no_catalog_never_defaults`; vectors `*_is_loud` |
| L7 | Gates filter but never reorder: a cheap chain is a subsequence of `catalog_order(catalog)` | (design, no incident yet) | `l2_l4_l5_l6_cheap_gates` (subsequence assertion) |

## Decisions

| Behaviour (kept on purpose) | Why | Date | Pinned by |
|---|---|---|---|
| A cheap-chain entry whose catalog `provider` is `null` skips both the allowlist and the credential gate even when `keyless: false`; on the wire it renders as `provider = ""` with `keyless = 0` | `None` is the typed "unknown provider" (never the text "1", incident e82f008); a gate on an unknown provider has nothing to check. The shell must treat `provider "" + keyless 0` as undispatchable rather than key-requiring | 2026-09-19 | vector `T02_keyed_entry_unknown_provider_skips_credential_gate` (T02 report) |

## Rule for this directory

`kernel/laws/<pillar>.md` lists every law of that pillar with its mechanism.
CI check (to add with P2): every `L\d+` id in this file must appear in
`kernel/dispatch-policy/tests/` or `kernel/vectors/`. Presence-only, like
the AGENTS.md grep in bestmodel S25c — content honesty stays human.
Run byproduct: a red proptest writes `tests/*.proptest-regressions`
(next to the source) and replays it on every later run, so one discovered
counterexample turns the suite permanently red until the file is removed;
never commit it while the law it pins is still failing (T02).

## Not laws (yet)

- L3's determinism clause ("pure function of catalog content") currently
  holds only for catalogs with distinct `(keyless, context_length, ref)`
  triples: `catalog_order` sorts stable, so duplicate refs tie in FILE
  order and reversing the file reverses the chain
  (`laws::l3_cheap_order` fails at `PROPTEST_CASES=5000`, ~20 % of plain
  runs; T02). Candidate: total-order tie-break (e.g. append provider to
  the sort key) or a stamped-catalog invariant "refs are unique" plus a
  typed rejection. Pinned by vector `T02_l3_duplicate_ref_ties_keep_file_order`.
- Registry-first rules for `mid`/`expensive`/`vision` are a faithful port
  (vectors `mid_*`, `expensive_*`, `vision_*`), not a law: nobody has
  stated the property they should satisfy. Candidate: "a paid tier never
  resolves to a free-only provider".
- Direct-id path applies no credential gate (mirrors the shell). Candidate
  law once the shell is replaced: "every dispatched ref passed a gate".
