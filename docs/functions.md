# Documentação de `somar(a, b)`

## Descrição

A função `somar` recebe dois valores numéricos, `a` e `b`, como entradas e retorna a soma desses valores.

## Parâmetros

* `a`: O primeiro valor numérico a ser somado
* `b`: O segundo valor numérico a ser somado

## Retorno

A função retorna a soma de `a` e `b`, que é um valor numérico.

## Exemplo

Este código demonstra como invocar a função `somar`:
```python
resultado = somar(2, 3)
```

No exemplo acima, `resultado` será igual a `5`, pois `somar(2, 3)` retorna a soma de 2 e 3.
