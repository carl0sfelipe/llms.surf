v4 plan — the pipeline

what ships in this cut. not a product catalog.

// the pipeline today

One 4-stage pipeline ships in this cut: spec open → dispatch → oracle → incident. God modes, rings, critic-guard, watchdog, and the usage hub are in the tree.

  • stage 1 — spec open: the oracle is frozen by sha256 at ring open. Goalposts don't move.
  • stage 2 — dispatch: 1% frontier thinking / 99% cheap sweat, picked per task.
  • stage 3 — oracle: gates read artifact content on disk. exit 0 is the only victory.
  • stage 4 — incident: every failure becomes an incident; every incident becomes a mechanism.

// the discipline

  • A number on a public page has to match the tree, or it does not ship.
  • Victory is a green oracle — never a model's opinion of itself.
  • A rule without a mechanism is debt, not protection.
