# Vector CDE — infográfico

Página HTML única, autocontida e mobile-first, que explica o projeto **Vector CDE**
(fundo imobiliário + compute de IA em Ciudad del Este, Paraguai) para leigos,
com caixas expansíveis e quatro níveis de entrada (bootstrap → high-stakes).
